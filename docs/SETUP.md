# 阿瓦隆 · 独立分享版

版本：2026-10-19 · AI策略、再来一局与格式容错修复版。支持 5–10 人真人局域网联机、八种角色和可选 Gemini 文字 AI 玩家。

**这个包没有 API 密钥。** 不包含原作者的 `.env`、房间数据库、玩家会话、AI 记忆和日志。没有密钥也能玩真人对局；要用 AI，请自己申请并配置。网页角色素材已包含，不需要生成图片。

## 1. 安装与启动

1. 安装 [Node.js](https://nodejs.org/) 24.12 或更新版本（包含 npm），完整解压 ZIP。
2. 在解压后的 `avalon` 文件夹打开终端，执行：

```sh
npm run setup:tools
npm run lan
```

第一次安装需要联网。程序不需要构建，不需要另一个项目，也不需要 Python。不要直接双击 HTML。

- 本机浏览器打开 `http://127.0.0.1:4180/`。
- 多手机：电脑和手机连接同一 Wi-Fi，所有人打开终端输出的局域网地址，例如 `http://192.168.x.x:4180/`。不要给朋友发 `127.0.0.1` 或 `localhost`。
- 电脑也建议使用相同局域网地址，避免切换地址导致浏览器会话不同。
- 建房 → 选择人数及角色 → 分享邀请链接/二维码 → 每人认领座位并准备 → 房主开始 → 查看身份并确认。
- 电脑需一直运行服务。停止用 Ctrl+C；重启同一目录可恢复数据库中的房间。没有公网部署，不同网络的朋友不能直接访问此局域网地址。
- 系统防火墙如询问，按需允许可信本地网络访问。不要把此开发服务直接暴露到公网。

## 2. Google AI Studio 免费层 API 配置（可选）

免费的是符合条件的项目/模型额度，API key 本身不保证免费或无限调用。

1. 打开 [Google AI Studio API Keys](https://aistudio.google.com/apikey)，登录自己的 Google 账号。按页面提示创建项目和 API key；已有项目可选择相应项目。
2. 在 AI Studio 的项目/配额页面确认项目处于 **Free Tier**。只想使用免费额度时，不要启用 Billing、升级付费层或关联付费项目。账号、地区及模型可用性以自己的页面为准。
3. 将本目录 `.env.example` 复制为 `.env`：
   - macOS / Linux：`cp .env.example .env`
   - Windows PowerShell：`Copy-Item .env.example .env`
4. 用文本编辑器打开 `.env`，填入自己新建的 key：

```dotenv
GEMINI_API_KEY=在这里填写你自己的密钥
GEMINI_MODEL=gemini-3.8-live
AI_MAX_CALLS_PER_GAME=0
AI_MIN_INTERVAL_MS=12000
```

不要添加引号以外的说明到密钥值里，不要将密钥发到群聊或放进前端。

5. 执行一次简短真实连通检查：

```sh
npm run ai:check
```

6. 成功后重启 `npm run lan`。房主在大厅的空座位上主动添加 AI；普通房间不会自动补 AI。可使用多名 AI，但共享同一密钥额度。

本包保留原项目配置的 `gemini-3.8-live`。请通过下方官方价格页面及自己的 AI Studio 确认该模型当前是否可用、是否有免费层及剩余额度；打包不代表对接收者账号的免费资格作出保证。项目不会自动替你开通计费或切换模型。

`AI_MAX_CALLS_PER_GAME=0` 只取消本程序的每局总调用上限，**不是 Google 无限额度**；可以改为 40 等正整数限制单局调用。默认每次请求间隔 12 秒，错误不会无限重试。`ai:check` 会消耗一次真实请求；`ai:verify` 是完整模型对局验证，会多次调用 API，非日常启动必需。

当前页面只提供文字。Live 适配器使用工具返回决策，协议采用音频模态，但程序丢弃音频，不录音、不播放、不保存语音；不要据此推断付费项目不会产生费用。

官方说明：
- [获取 API key](https://ai.google.dev/gemini-api/docs/api-key)
- [免费层与计费](https://ai.google.dev/gemini-api/docs/billing)
- [模型价格与免费层](https://ai.google.dev/gemini-api/docs/pricing)

### 本次修复

修正 Live 提示词中 JSON 输出与工具调用的冲突。模型附带的策略记忆格式或证据引用不合法时，整体丢弃该补丁，保留该玩家上次有效记忆，不阻塞已通过校验的行动或发言。非法行动、越界选项、额外顶层字段及不合格发言仍严格拒绝；不代表所有格式错误都能自动恢复。没有新增无限重试。

### 本版 AI 策略

包内完整包含 `ai/skills/play-avalon/`（17个文件）。每次模型调用加载共同策略、本人角色策略、当前阶段策略；模型只接收自己的过滤视角、公开历史/发言及合法行动。事实、推测、公开立场与诈唬分开保存；允许游戏内假跳、配合和挡刀，行动仍经服务器规则校验。不要删除该目录，缺失策略时AI会暂停。

可选执行 `npm run ai:skill:check`：两个合成局面的真实模型请求，分别检查决胜任务牌与公开发言注入；会消耗额度，报告生成到 `.local/ai/`。它不是完整对局或胜率评测。已有两个真实案例通过，但完整策略对局、胜率对比及真人多设备仍待验证。

## 3. 常见问题

- `MISSING_API_KEY` / 未配置：检查 `.env` 位于解压根目录，修改后重启服务。纯真人游戏无需 key。
- `AUTH_FAILED`：检查密钥、项目和 API 权限；不要将完整错误或密钥公开。
- `RATE_LIMIT` / 429：额度不足，稍后再试或减少 AI 数量。不要为了重试自动开启计费。
- `MODEL_UNAVAILABLE`：先在自己的 AI Studio 检查模型可用性。可自行将 `GEMINI_MODEL` 改为适配器支持的 `gemini-3.8-flash` 或 `gemini-3.5-flash-lite`，但先核实免费资格与额度，不保证任何账号都可调用。
- `TIMEOUT` / 网络错误：确认电脑能访问 Google API。Live 还需要网络支持 WebSocket。修复后由房主点“重试 AI”，不要重复创建房间来重试。
- 二维码依赖缺失：在当前目录重新运行 `npm run setup:tools`。
- 端口被占用：关闭旧服务再启动；更改端口时需要所有人使用新地址。

## 4. 当前游戏房规与操作

点头像选队；左上眼睛查看私人身份；顶部五个任务人数节点打开历史；设置里可看规则与全部角色图鉴。

**刺杀阶段亮牌房规**：正义能查看全员准确角色；邪恶能查看全部邪恶队友的角色，包含奥伯伦，奥伯伦也能看其他邪恶队友。此前阶段奥伯伦仍不互认。已亮牌的邪恶队友不能作为刺杀目标。终局全员公开。此项是本项目自定义规则，区别于原版刺杀前不亮牌。

**再来一局**：对局结束后，房主点击底部“再来一局”，全员回到同一个大厅。房间码、昵称、座位、角色配置和AI席位保留；真人重新准备，房主再开始，服务器重新发身份。身份确认、发言和本局AI记忆不带入新局，上一局任务历史不再显示，请先看完复盘再点击。其他玩家看到“等待房主再来一局”。若有人已进入另一活动房间，需先退出那边再重开。

断线保留座位，不会自动让 AI 替真人行动。请保留浏览器 Cookie；清除 Cookie 或更换浏览器不等于恢复原座位。不支持中途顶替玩家。

## 5. 文件与开发验证

- `src/`：规则、玩家视角及房间逻辑。
- `web/`：中文手机网页。
- `scripts/`：服务、模型适配和验证命令。
- `tests/`：自动测试。
- `ai/skills/play-avalon/`：共同、角色和阶段策略及原始技能参考文档。
- `.local/web-assets/roles/`：已优化的角色素材（请保留隐藏目录）。
- `.local/toolchain/`：首次安装后生成的依赖。
- `.local/multiplayer/`：运行后生成的私密房间数据库；不要转发。
- `.env.example`：无真实密钥的配置示例；`.env` 由你自己创建。

```sh
npm run typecheck
npm test
npm run demo
```

`demo` 是测试脚本，不是真实 AI。浏览器自动测试需要另装浏览器，可选执行 `node .local/toolchain/node_modules/playwright/cli.js install chromium`，再执行 `npm run test:browser`。真人多设备体验仍需实际试玩，测试通过不代表公网安全或正式产品验收。

再次分享时请使用原始 ZIP，或至少去掉 `.env`、`.local/multiplayer/`、`.local/ai/`、日志与会话数据。不要直接压缩运行后的整个目录。
