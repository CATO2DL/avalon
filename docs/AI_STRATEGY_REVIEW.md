# AI 策略评测汇总

2026-10-20。本文件只公开方法和汇总结果，不包含真实对局输入、玩家发言原文、角色对应、房间标识或私人记忆。

## 实际实现

- `src/ai-brief.ts` 仅从玩家过滤视角和公开发言派生决策摘要：比分、任务门槛、否决风险、合法已知信息、公开争议与本人立场。完整公开聊天仍单独发送；发言主张不被当成已证实事实。
- `scripts/avalon-strategy.mjs` 每次加载共同、本人角色和阶段策略。公开承诺不约束秘密任务牌；关键赢点优先。梅林不能把私有知识编造成公开证据。
- `scripts/ai-runtime.mjs` 在本地数据库记录每次通过校验的决策及固定的失败阶段。旧失败尝试不会冒用后续成功结果。记录属于私人数据，不能公开分享。
- Live 超时记录连接、等待、生成、校验或纠正阶段，不保存原始模型响应。维持原超时与有限纠正，不自动换模型或无限重试。

## 对照与结果

使用当前配置的 `gemini-3.8-live`，同模型、同参数：30 秒会话上限、AUDIO、4096 输出 token、默认温度。六个局面做冻结基线与候选策略配对，其中四个来自历史、两个为合成边界局面；另有三次探索性复测，不能混入配对结论。

总计 15 次真实会话，11 次有效、4 次超时。生成轮次观测到 14 次，考虑失败会话的未回报部分，保守上限为 22，未超过预设 24 轮预算。本轮没有新跑完整真实模型对局，也没有胜率提升结论。

| 观察项 | 结论 |
| --- | --- |
| 梅林无收益暴露 | 有效回放未复现，但基线也未复现，不能归功于修改 |
| 发言互动 | 配对结果仍有机械地询问队长；探索版略具体，样本不足 |
| 阻止正义第三次任务成功 | 基线与首候选仍有为掩护身份而出成功的问题；探索复测超时 |
| 确定的第三张任务失败赢点 | 基线和候选都选择失败，无新增提升证据 |
| 第五次否决风险 | 基线超时、候选通过；超时不能记成战术失败 |
| 延迟与稳定性 | 小样本不能证明改善，4 次超时仍须定位 |

216 项自动测试及类型检查通过。新增测试覆盖派西维尔歧义、关键门槛、完整公开聊天、私人记忆隔离与固定超时阶段。工程验证不代表 AI 已达到熟练玩家水平。

## 本地审查与回放

只读审查已有数据库，不触发 API：

```sh
node scripts/ai-record-audit.mjs PATH_TO_PRIVATE_DATABASE.sqlite .local/ai/new-audit
```

先人工选取不超过六个局面，冻结当时合法视角和基线策略，再修改候选策略。准备好的私有案例可运行：

```sh
node --env-file-if-exists=.env scripts/ai-replay.mjs .local/ai/selected-cases.json .local/ai/new-report.json
```

**回放会消耗真实 API 额度。** 配对最多十二次会话；每会话最多一次格式纠正，生成轮次上限二十四。工具拒绝覆盖已有输出，不自动切换模型。`--candidate-only` 仅用于单独标注的探索复测，不能冒充配对。

导出的案例、输入、输出与记忆必须保留在被忽略的 `.local/`，不要上传 GitHub。当前仓库只提供工具和合成测试，不提供私有案例。后续优先按超时阶段定位故障，再对同一冻结局面做重复配对；继续评估非法行动、事实矛盾、暴露、赢点、发言、延迟及调用量。
