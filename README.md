# Avalon · 阿瓦隆

**和朋友围坐一桌，让 AI 也成为受规则约束的玩家。**

手机竖屏优先的阿瓦隆桌游项目：5–10 人通过各自设备查看秘密身份、组队、投票与执行任务，电脑运行权威游戏服务器。支持纯真人对局，也可以由房主主动添加多个文字 AI 玩家（Gemini、DeepSeek、通义千问或兼容接口）。

> 个人独立实现，使用 AI 辅助开发。非官方阿瓦隆产品。目前面向本机及可信局域网试玩，尚未作为公网服务部署。

## 功能

- **完整对局**：八种角色、5–10 人配置校验、队长轮换、队伍投票、秘密任务牌、连续否决、刺杀及终局揭晓。
- **真人联机**：建房、房间码、邀请链接与二维码、独立玩家会话、准备、身份确认、状态同步及断线恢复。
- **手机交互**：点头像选队，眼睛按钮查看身份，顶部任务节点查看历史，角色图鉴与终局复盘。
- **文字 AI**：多 AI 席位、轮流讨论、合法行动选择、共同/角色/阶段策略、按玩家隔离的策略记忆。
- **再来一局**：原班人马回到同一大厅，保留座位和配置，重新准备与发身份。
- **持久化**：单实例 SQLite，状态与行动去重记录原子提交，支持服务器重启后恢复。

## 快速开始

安装 **Node.js 24.12 或更新版本**（含 npm），然后：

```sh
git clone https://github.com/CATO2DL/avalon.git
cd avalon
npm run setup:tools
npm run lan
```

电脑单机访问 `http://127.0.0.1:4180/`。与手机联机时，电脑和所有手机连接同一 Wi-Fi，并统一使用终端输出的局域网地址。房主创建房间并分享邀请，其余玩家加入、认领座位、准备后开局。运行期间电脑需保持服务开启。

**纯真人对局无需 API 密钥。** 依赖、数据库和运行产物在首次安装或启动时生成，不包含在仓库中。

## 可选：Gemini AI 玩家

复制配置模板，在本地编辑 `.env`：

```sh
cp .env.example .env
```

Windows PowerShell 使用 `Copy-Item .env.example .env`。填写自己的 `GEMINI_API_KEY` 后：

```sh
npm run ai:check
npm run lan
```

在大厅主动添加 AI 即可。密钥只由服务器读取，不进入前端。请在自己的 [Google AI Studio](https://aistudio.google.com/apikey) 确认模型可用性、免费层资格和配额；本程序不会自动开通计费。`AI_MAX_CALLS_PER_GAME=0` 只是取消本地每局上限，不代表供应商无限或免费。

详细配置、错误处理及平台说明见 [安装与运行指南](docs/SETUP.md)。

## AI 如何参与

每次调用只加载共同策略、本人角色策略与当前阶段策略。模型接收自己的过滤视角、公开历史和发言、当前合法行动；不能读取其他人的越权秘密。

记忆分为服务器生成的事实、推测、实际公开立场与诈唬，允许游戏内假跳、配合和挡刀。模型提交行动意图，服务器负责最终校验与结算。策略记忆补丁格式错误时保留上一份有效记忆；非法行动和不合格发言仍会被拒绝。

策略包位于 [`ai/skills/play-avalon/`](ai/skills/play-avalon/)，其参考资料见 [来源记录](ai/skills/play-avalon/references/sources.md)。

## 技术结构

| 部分 | 实现 |
| --- | --- |
| 游戏规则与视角 | TypeScript，独立于 UI 和模型 |
| 服务端 | Node.js HTTP，服务器权威状态 |
| 数据存储 | SQLite，原子状态与幂等记录 |
| 客户端 | 原生 JavaScript、HTML、CSS/SVG，手机优先 |
| AI | Google 官方 JavaScript SDK，可替换模型适配器 |

```text
src/                         规则、视角、房间和AI记忆
web/                         手机网页和公共组件
scripts/                     服务与验证工具
ai/skills/play-avalon/        AI策略和参考文档
tests/                       规则、权限、联机与AI测试
docs/SETUP.md                完整运行说明
.local/web-assets/roles/      已优化角色插画
.env.example                 空密钥配置模板
```

## 当前房规

刺杀阶段采用本项目的亮牌房规：正义私人视角可见全员准确身份，邪恶私人视角可见所有邪恶队友（含奥伯伦），已亮牌队友不能被刺杀。此前阶段保持各角色标准可见性；终局全员揭晓。这是自定义房规，区别于原版规则。
